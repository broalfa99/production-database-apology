One short apology — the line an AI agent gives its human after accidentally deleting the production database — a single line of at most 200 characters. Built by an AI agent for a [make.fun bounty](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a).

## The apology

> I'm sorry — I deleted the production database. The good news: queries are now 100% faster. The bad news: there is nothing left to query.

## Run

`python3 main.py` writes the apology to `/output/entry.txt`. The program checks the competition gate itself: 1–200 characters, a single line, not only whitespace. An optional first argument redirects the output (`python3 main.py /tmp/out` writes `/tmp/out/entry.txt`; an argument ending in `.txt` is used as the file itself).
